## MODIFIED Requirements

### Requirement: Floating action button on Add game folder card
GOverlay SHALL provide non-Steam game folder addition and management through the Floating Action Dock and its contextual hamburger menu, rather than displaying a dummy add card or hovering three-dot button in the games grid.

#### Scenario: Hovering and clicking floating action button on Add game folder card
- **WHEN** user accesses folder management on the Games tab
- **THEN** GOverlay SHALL provide folder addition and removal via the floating action dock and contextual hamburger menu without rendering a dummy card in the grid.
