## Purpose

Ensures complete, centralized, and reliable diagnostic logging for all tools managed by GOverlay, facilitating troubleshooting across all supported game sessions.

## ADDED Requirements

### Requirement: Centralized tool log synchronization
The system SHALL discover and synchronize log files generated by game tools (including `optiscaler.log`, `dlss-enabler.log`, `fakenvapi.log`, `vksumi.log`, `vkbasalt.log`, `lsfg.log`, `mako.log`, and `bgmod-uninstaller.log`) from the game directory into the central logging directory `~/.local/share/goverlay/logs/<GameDirName>/`.

#### Scenario: Case-insensitive OptiScaler log synchronization
- **WHEN** OptiScaler writes `optiscaler.log` or `OptiScaler.log` in the game directory during game execution
- **THEN** the system discovers the file regardless of casing and synchronizes its full content into `~/.local/share/goverlay/logs/<GameDirName>/optiscaler.log`.

#### Scenario: DLSS Enabler and FakeNVAPI log synchronization
- **WHEN** DLSS Enabler writes `dlss-enabler.log` or `fakenvapi.log` in the game directory
- **THEN** the system synchronizes those files into `~/.local/share/goverlay/logs/<GameDirName>/dlss-enabler.log` and `~/.local/share/goverlay/logs/<GameDirName>/fakenvapi.log`.

#### Scenario: bgmod-uninstaller log synchronization
- **WHEN** `bgmod-uninstaller` runs in the game directory or is triggered via GOverlay
- **THEN** `bgmod-uninstaller.log` is recorded in or mirrored to `~/.local/share/goverlay/logs/<GameDirName>/bgmod-uninstaller.log`.

### Requirement: MangoHud diagnostic logging
The system SHALL capture MangoHud diagnostic messages from the game execution process and store them in `mangohud.log` in both the central log directory and the game directory.

#### Scenario: MangoHud diagnostic output capture
- **WHEN** a game is launched with MangoHud enabled
- **THEN** diagnostic, initialization, and error messages from MangoHud are captured and written to `~/.local/share/goverlay/logs/<GameDirName>/mangohud.log` and `<GameDir>/mangohud.log`.

### Requirement: GOverlay UI log viewer tab integration
The GOverlay user interface SHALL open the corresponding log file for the currently active tool tab and sub-option selection.

#### Scenario: Opening DLSS Enabler log from Upscaler tab
- **WHEN** the user has DLSS Enabler selected in the Upscaler tab and clicks "Open Log File"
- **THEN** the interface opens `~/.local/share/goverlay/logs/<GameDirName>/dlss-enabler.log`.

#### Scenario: Opening MangoHud log from MangoHud tabs
- **WHEN** the user is on any MangoHud configuration tab and clicks "Open Log File"
- **THEN** the interface opens `~/.local/share/goverlay/logs/<GameDirName>/mangohud.log` if it exists, falling back to `bgmod.log` if uninitialized.
